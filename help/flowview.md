Окно потока
==================

![Поток](./images/FlowView.png)

Назначение окна потока
=========================

Окно потока предназначено для отображения того, что «происходит с» данными для заданного ID по мере прохождения времени. Поток — это поток времени или сообщений. Цель — визуализировать, что происходит по мере прохождения времени. Экран очень загружен, но всё имеет одну цель — показать байты данных среди списка всех кадров с этим ID.

Выбор ID для потока
=======================

Вдоль самой левой стороны окна находится список каждого захваченного ID кадра. Вы можете выбрать любой из этих ID. Как только вы выберете ID, вы увидите количество кадров с этим ID справа от списка ID (внизу блока управления воспроизведением).

Просмотр потока
=================

Есть различные способы отображения байтов данных для текущего кадра. Ближе к середине окна находятся 8 текстовых полей, показывающих текущее значение каждого байта данных. В правой части окна находятся две визуализации. Вверху находится сетка 8x8, визуализирующая каждый возможный бит в CAN-сообщении. Биты, которые белые, в данный момент 0 или выключены. Биты, которые чёрные, — 1 или включены. Биты, которые зелёные, недавно включены в этом кадре. Они были 0/выключены в опорном кадре. Биты, которые красные, недавно выключены в этом кадре. Эти биты были 1/включены в опорном кадре.

Ниже представления сетки 8x8 находится графическое представление. «+» в центре отмечает «текущее» время. Таким образом, вы можете видеть как в будущее, так и в прошлое (относительно текущего кадра) в этом представлении. Все 8 байт данных построены в соответствии с их значением. Таким образом, вы можете видеть на графике, что происходит со значением по мере прохождения времени.

Между этими тремя представлениями у вас должно быть очень хорошее представление о том, как байты данных изменяются со временем.

Управление потоком
=====================

Экран имеет множество способов управления потоком. В блоке «Управление воспроизведением» находится 6 иконок в сетке 3x2. Верхние иконки означают (слева направо): Назад на один кадр, Стоп, Вперёд на один кадр. Нижние иконки означают: Воспроизведение назад, Пауза, Воспроизведение вперёд. Скорость воспроизведения используется для управления скоростью потока. Вы можете повышать и понижать это значение даже во время воспроизведения потока, и оно будет изменять скорость потока в реальном времени. Вы можете выбрать «Циклическое воспроизведение», чтобы продолжать циклить снова и снова. Возможно выбрать «0» как интервал кадров. Это заставит программу прогрессировать так быстро, как она может. Вероятно, это не будет значительно быстрее, чем интервал кадров 1, но будет немного быстрее.


Дополнительные параметры управления
===========================

Ниже блока «Управление воспроизведением» находится набор из трёх флажков. «Режим реального времени» заставит окно потока удерживать текущий кадр на последнем полученном кадре от аппаратуры захвата. Это опция «реального времени», при которой поток будет происходить в реальном времени по мере поступления кадров. «Синхронизировать окна» заставляет поток в этом окне обновлять позицию в главном окне так, чтобы главное окно всегда находилось на текущей позиции воспроизведения потока. «График по метке времени» заставляет «Временную ось» внизу графического представления быть в секундах или микросекундах. Отключение этого заставит эту ось быть в номере кадра.

Опорные значения
=================

Ранее упоминалось, что биты в сетке 8x8 окрашены в зависимости от того, недавно ли они
включены/выключены или находятся в стабильном состоянии по сравнению с опорным. Что такое опорное? Посмотрите слева от сетки 8x8. Опорные значения здесь используются в качестве опорных для сетки 8x8. Вы можете установить эти значения на что-то статическое, а затем видеть, как биты сравниваются с этим статическим опорным. Или над опорными значениями находится флажок «Автоопорное», если он нажат, то последний кадр используется как опорный для текущего. У обоих вариантов есть преимущества. Статическое опорное можно использовать для просмотра, как вещи изменяются по сравнению с, скажем, самым первым кадром. Автоопорное показывает, как данные изменились от кадра к кадру. Любой может дать интересные результаты. Значения по умолчанию для статического опорного берутся из значений, которые имеет первый кадр. Вы можете свободно менять их на любое значение от 0 до 0xFF.


Поиск конкретных значений
===========================

Наконец, можно искать конкретные значения. «Значения поиска данных» обычно по умолчанию равны -1. Но если в одном из этих полей найдено значение, отличное от -1, то оно будет использовано как значение поиска. Каждый раз, когда поток воспроизводится (вперёд или назад), он будет сравниваться с значениями поиска. Если есть совпадение, воспроизведение автоматически остановится. Это можно использовать для быстрого воспроизведения, пока вы не дойдёте до конкретного значения. Одно из применений — искать известное значение, которое предшествует важному разделу, который вы хотите проанализировать более глубоко. Также, в том же духе, если вы нажмёте в сетке 8x8 битов, вы увидите, что ячейка, на которую вы нажали, имеет текст, ставший синим и жирным. Любой бит, который вы выбрали таким образом, также будет действовать как способ остановить воспроизведение. Если этот бит изменится, будучи установлен или сброшен, воспроизведение остановится. Нажмите на ячейку снова, чтобы отменить выбор.
