Окно пользовательской отправки
=====================

![Окно пользовательской отправки](./images/CustomSender.png)

Общий обзор
====================

Это окно позволяет создавать пользовательские кадры, которые будут отправляться на одну из CAN-шин. Применений бесконечное множество.
Оно может использоваться для генерации валидного трафика для управления подключённым оборудованием. Оно может использоваться для проверки различных идей
о том, как взаимодействовать с другими устройствами. Оно может воспроизводить кадры с одной шины на другую, но с
модификациями.


Макет представления
=====================

Этот экран представлен в виде таблицы данных.

* Первое поле — «En», что означает Включено. Если галочка установлена,
  то эта строка будет активна.
* Второе поле — «Bus» и устанавливает, какую шину использовать для отправки.
* Третье поле — «ID» — это ID для отправки. Он может быть указан в шестнадцатеричном или десятичном формате.
* Четвёртое поле — «Len» — устанавливает количество байт данных для этого кадра.
* Пятое поле — «Data» — указывает, какие значения будут отправлены для следующего кадра. Эти значения могут быть
  автоматически обновлены модификаторами, которые будут рассмотрены позже.
* Шестое поле — «Trigger» — указывает, когда этот кадр будет отправлен. Правильный синтаксис для триггеров
  рассмотрен позже.
* Седьмое поле — «Modifications» — указывает, как байты данных для этого кадра будут изменены для
  следующего отправленного кадра. Полный синтаксис для этого рассмотрен позже.
* Последнее поле — «Count» — автоматически заполняется количеством кадров, которые были отправлены в
  результате этой строки.


Написание правил триггеров
=======================

Сначала следует отметить, что каждая строка может содержать несколько триггеров. Каждый триггер разделяется запятой ','.

Триггерам разрешено иметь одно или несколько условий. Каждое условие внутри одного триггера разделяется
пробелом ' '.

Программа реализует следующие условия:

* id — Установить триггер для активации при получении кадра с заданным ID. Синтаксис: 'id'
  за которым следует числовой ID, который вы хотите отследить. Пример: 'id0x200'
* ms — Установить количество миллисекунд ожидания. Это условие действует по-разному в зависимости от того,
  установлено ли также соответствие по ID. Если да, то ms вызовет задержку на запрошенное количество миллисекунд
  после получения кадра с этим ID. Если нет, триггер будет постоянно срабатывать каждый раз, когда пройдёт запрошенное количество
  миллисекунд. Синтаксис: число желаемых миллисекунд, за которым следует 'ms'. Например:
  '40ms'.
* x — Разрешить этому триггеру сработать только заданное количество раз. Синтаксис: количество раз, которое вы хотите, чтобы триггер
  сработал, за которым следует 'x'. Например: '100x'.
* bus — Срабатывать только при получении кадра с заданным ID на указанной шине. В противном случае кадр-триггер
  может прийти с любой шины. Синтаксис: 'bus' за которым следует '0' или '1'. Например: 'bus0'

Теперь полный пример строки триггера: «id0x200 5ms 10x bus0,1000ms» Этот триггер означает: Сработать при получении кадра с ID 0x200
на шине 0. Подождать 5 миллисекунд перед отправкой и разрешить это произойти максимум 10 раз. Также всегда срабатывать каждые
1 секунду и никогда не прекращать это делать.


Написание модификаций
=======================

Как и с триггерами, вы можете иметь несколько модификаций на строку; каждая из которых разделяется запятой ','.

Модификации всегда начинаются с байта данных для изменения. Синтаксис: 'D' или 'd' за которым следует число от 0 до 7.
Например: 'D4'. За этим всегда следует знак равенства '='. Далее следует строка операндов и
операций.

Операнды имеют специальный синтаксис. Каждый операнд может иметь несколько секций, разделённых двоеточиями ':'.

* D — Байт данных. Указывает, какой байт данных 0 - 7 из данного кадра использовать для этой операции. Если указан
  сам по себе, он будет ссылаться на данные в разделе «Data» этой строки. Синтаксис: 'd' или 'D' за которым
  следует число 0 - 7. Пример: 'D3'.
* ID — Вместо извлечения данных из байтов данных этой строки, извлечь из последнего полученного кадра с заданным ID.
  Синтаксис: 'ID' за которым следует двоеточие ':' и ID для сопоставления. Пример: 'ID:0x200'
* BUS — Ограничить, с какой шины может прийти кадр, используемый для извлечения байтов данных. Синтаксис: 'BUS' за которым следует
  двоеточие ':' и 0 или 1 для указания, какую шину использовать. Пример: 'BUS:0'
* <ЧИСЛО> — Вместо использования байта данных откуда-либо, вы можете использовать числовой литерал. Синтаксис
  тот же, что и для любого числа — либо серия цифр, либо 0x за которым следует серия цифр и A - F для указания
  шестнадцатеричного числа. Пример: 0x10.

Несколько полных примеров операндов:

* «bus:0:id:0x120:D3» = Извлечь байт 3 из последнего кадра с ID 0x120, который пришёл на шину 0.
* «0x200» = Использовать числовое значение 0x200 напрямую.
* «id:0x200:D7» = Извлечь байт 7 из последнего полученного кадра с ID 0x200.

Каждый операнд обычно следует за операцией, а затем за вторым операндом. Если операция или второй операнд не найдены, это
тоже нормально. Таким образом модификатор может быть таким простым, как «D0 = D1», если вы решите. Операнды также могут быть напрямую связаны так, что
вывод последней операции используется как левый операнд для следующей операции. Это будет показано позже.

Модификаторы могут использовать следующие операции:

* \+ — Сложить два операнда. Пример: «D1 + D2»
* \- — Вычесть второй операнд из первого. Пример: «D1 - D2»
* \* — Умножить два операнда. Пример: «D1 * D2»
* \/ — Разделить первый операнд на второй. Пример: «D1 / D2»
* \& — Выполнить битовую операцию AND на двух операндах. Пример: D1 & 0x20
* \| — Выполнить битовую операцию OR на двух операндах. Пример: D1 | 0x10
* \^ — Выполнить битовую операцию XOR на двух операндах. Пример: D1 ^ 0xD2

Собрав всё это вместе, получаются полные модификаторы. Для простоты все операции
выполняются слева направо. Нет особого порядка операций, как в обычной математике.

Вот несколько примеров:

* «D0=D0+1» = Взять значение в D0 в байтах данных этой строки, добавить 1, и сохранить обратно в D0.
* «D1=ID:0x200:D3+ID:0x200:D4&0xF0» = Извлечь байт 3 из последнего полученного кадра с ID 0x200 и сложить его
  с байтом 4 из того же полученного кадра. Выполнить AND этого нового значения с 0xF0 и, наконец, сохранить в D1 байтов данных для этой строки.
* «D2=D4 * 10 + D3 & 0x3F» = Умножить байт 4 на 10, сложить новое значение с байтом 3, выполнить AND результата с 0x3F и сохранить в байте 2.
